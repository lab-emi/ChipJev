# SKY130 and System Two study (protocol topo-v4): ChipJev on the open SKY130 PDK, and System One versus System Two decisions

This study extends the PTM 45 nm study ([../ptm45](../ptm45/README.md)) with two preregistered
stages (see [PROTOCOL.md](PROTOCOL.md); frozen 2026-09-24 23:27 CEST as **topo-v4**, with 45
hashed files and 360 runs). It produces Table III and the System Two rows of Table II.

* **sky130**: AnalogCoder-Pro's twelve task specifications on SkyWater SKY130 (TT, 1.8 V,
  100 pF), ChipJev (fine-tuned Laya decisions) versus eight-worker joint TPE and random search,
  five seeds, 1,024 evaluations, unchanged methods (today `chipjev.circuits.sky130_devices`
  and `chipjev.simulation.sky130`).
* **system2**: the PTM 45 nm tasks, ChipJev with Laya's System One decisions versus the
  identical search whose typed questions are answered by DeepSeek-V3 or GPT-5-mini through
  OpenRouter (today `chipjev.decisions.llm`).

[DEVIATIONS.md](DEVIATIONS.md) records execution notes; the reported System Two runs are those
of the separately frozen addendum [system2b](system2b/PROTOCOL.md) (protocol topo-v4-system2b),
which replaced the first System Two stage after a prompt ambiguity (DEVIATIONS item 3). The
protocols and the evidence name the code by its paths at the freeze (for example
`chipjev_topo_v4.sky130`, `scripts/topo-v4-run.py`, `experiments/topo-v4`), which live on
unchanged in the optional local `reproduce/frozen-code.tar.gz` snapshot
([source snapshot requirements](../../reproduce/README.md)); the map to the
current package is in [experiments/README.md](../README.md). `report/RESULTS.md` and
`report/summary.json` are generated by `reproduce/report_sky130_system_two.py` from the archive
in `results/` (MANIFEST.json lists every hash).

## Results

- **SKY130** (180 runs): ChipJev qualifies **60/60** runs, eight-worker TPE 51/60 and random
  search 24/60. Against TPE's task medians ChipJev records 7 numeric wins, 3 feasibility wins
  (multi-stage op-amps) and 2 ties, with no loss; it reaches TPE's final quality **4.5x sooner**
  (95% CI 3.5-7.2x, 9 tasks) with 3.7x fewer simulations; its first qualified design appears
  after 0.76 s median (TPE: 16 s); median run 40 s (TPE 58 s, random 65 s). Online simulations
  hitting the 2-s limit: ChipJev 1.1%, TPE 1.6%, random 3.9%.
- **System One versus System Two** (180 runs, addendum system2b): Laya decides in 9.8 ms,
  DeepSeek-V3 in 8.0 s (820x) and GPT-5-mini in 16 s (1,600x) for the same typed questions;
  1 of 61 DeepSeek-V3 calls and none of 60 GPT-5-mini calls were outside the type, no request
  failed. All three qualify 60/60 runs; against Laya's task medians each LLM wins, ties and
  loses 4/4/4 tasks. First qualified design: 0.24 s (Laya), 8.9 s and 16 s (LLMs); median run
  9.4 s versus 19 s and 27 s. System Two API cost: $0.24.
- **xschem**: all 135 qualified SKY130 designs (every method) export to xschem with the PDK's
  own symbols, and xschem's netlists reproduce the simulated devices, nodes and sizes
  ([xschem/](xschem/), frozen `scripts/topo-v4-xschem.py`); the median ChipJev design of each task is
  kept as a schematic.

## Reproduce

From the archive: `.venv/bin/python reproduce/report_sky130_system_two.py` (after
`reproduce/report_ptm45.py`, whose summary it reads), or all experiment reports with
`reproduce/reproduce-paper.sh`. Generated tables and figures go to `runs/reports/`;
the manuscript is maintained separately. Rerunning
executes the frozen code itself inside `runs/frozen` (`reproduce/reproduce-paper.sh --rerun`
runs everything, after restoring the three source snapshots listed in
[reproduce/README.md](../../reproduce/README.md)). Single stages, from the repository root (`frozen.py exec` runs the command in
`runs/frozen`, so the paths after `--` are relative to it; the system2b stage needs the OpenAI
client, which the locked environment lacks):

```bash
PY=$PWD/.venv/bin/python
uv pip install --python $PY openai==3.19.2
$PY reproduce/frozen.py materialize && $PY reproduce/frozen.py check
$PY reproduce/frozen.py exec -- taskset -c 0-7 $PY scripts/topo-v4-run.py --stage sky130
$PY reproduce/frozen.py exec -- taskset -c 0-7 $PY scripts/topo-v4-system2b.py --stage system2b   # needs OPENROUTER_API_KEY
$PY reproduce/frozen.py exec -- $PY scripts/topo-v4-xschem.py
$PY reproduce/frozen.py exec -- $PY scripts/topo-v4-archive.py
```

The runner refuses to start if any hashed source, the typed-decision weights or the SKY130
model files differ from `protocol.json` (the frozen tree takes the model files from
`frozen-source.tar.gz`). The study executed the SKY130 jobs in four parts on two core sets; the
as-executed host scripts are archived with the results (`results/stream-*.sh`, provenance only;
`stream-b.sh` ran the voided first System Two stage and was stopped, DEVIATIONS item 3). The
development checks (`scripts/topo-v4-run.py --dev`) and the freezes are not rerun: the
protocols exist. The SKY130 models are the AnalogGym-pinned archive
(`src/chipjev/simulation/pdk.py`, SHA-256 `bc46a070...`); the xschem export needs xschem and
the sky130A xschem library (`~/.volare/sky130A/libs.tech/xschem` or `CHIPJEV_SKY130_XSCHEM`).
